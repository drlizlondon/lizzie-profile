How it works

Safari Cleaner is a Safari Web Extension. Once installed it reads your open tabs on the device, groups them by website, and closes only the ones you select. It has no account, no server and no analytics.

Private by design. Your tabs never leave your iPhone — there’s nowhere for them to go.

Turning it on

Installing isn’t the last step — iPhone keeps four switches for Safari extensions, and two of them fail silently. Flip all four and Safari Cleaner appears in Safari.

  1. Settings → Screen Time → Content & Privacy → Web Content. Set it to Unrestricted. Anything stricter greys out every Safari extension, not just this one.
  2. Settings → Apps → Safari → Extensions → Safari Cleaner. Turn Allow Extension on.
  3. On that same screen, set All Websites to Allow — not Ask. With “Ask” the extension never shows up, so it looks like it was never installed.
  4. Quit and reopen Safari. Then open Safari Cleaner from the page menu — the aA icon in the address bar, not the share sheet.
